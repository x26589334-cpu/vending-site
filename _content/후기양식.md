# 설치 후기 (review/) — 양식과 규칙

픽프리의 데일리 글은 **설치 후기 하루 1편**이다. 픽포스(hsupporter.com)·H포스(hpos.co.kr)와 같은 방식이며,
2026-09-19 사용자 결정으로 **사진과 주제가 그 두 사이트와 겹쳐도 된다.**

기준 파일: `review/2026-09-19-seoul-gangnam-school-vending.html` (첫 글, 이걸 복사해서 쓴다)

## 기본 구조

1. **crumb** — 홈 / 설치후기 / {시도} {지역}
2. **제목(h1)** — `{지역} 무인자판기 설치` + 줄바꿈 + `<em>{업종} {특징}</em>`
3. **날짜 줄(`.art__meta`)** — `YYYY.MM.DD · {시도 정식명} {지역} · {업종}`
4. **사진 1장(`.art__fig`)** + figcaption
5. **리드 2문단** — 그 업종 자리의 특징, 현장에서 먼저 본 것
6. **h2 {지역} {업종}에 맞는 구성** — 기종·품목·가격대·결제·원격관리. `<ul>` 4줄로 요약
7. **h2 좋은 점과 어려운 점** — 장점 먼저, **단점도 반드시** 솔직히. 과장 금지
8. **h2 {지역}, 이런 자리가 잘 됩니다** — 그 지역 실제 동·상권 이름
9. **h2 {지역} 서비스 지역** — `.dong-line` 박스에 동 이름 나열 + 지역 페이지 링크
10. **h2 {지역} 무인자판기, 이렇게 시작하시면 됩니다** — 방문 상담 → 기종 결정 → 설치. 설치비 0원, 구입/렌탈/임대
11. **`.art-cta`** — 전화 + 상담 신청 버튼
12. **`.art-note`** — 사진 출처 문구(아래 필수)
13. **`.kw-box`** — 키워드 25~30개
14. **`.art-links`** — 관련 링크 4개

본문 분량 **1,200~1,600자**(태그 제외). 최근 글들과 문장·소제목이 똑같지 않게 바꿔 쓴다.

## 파일 이름과 경로

- 글: `review/{YYYY-MM-DD}-{지역slug}-{업종slug}-vending.html`
- 사진: `assets/img/review/{YYYY-MM-DD}-{지역}-{업종}.jpg`
- 지역 slug 는 `_content/후기지역목록.md` 의 slug 칸 그대로 쓴다(지역 페이지 주소와 같아야 링크가 맞는다).

## 지역 — 목록 순서대로

`_content/후기지역목록.md` 위에서부터 **✅ 가 없는 첫 줄**. 234곳을 한 바퀴 돌면 맨 위로 돌아가 **업종을 바꿔서** 다시.
글 안에서 그 지역의 지역 페이지 `region/{slug}-vending.html` 로 반드시 링크를 건다(서로 이어 줘야 둘 다 힘을 받는다).

## 사진 — 도구가 골라 준 후보에서 (2026-09-23 변경: 번호 순서대로 쓰지 않는다)

- 원본 풀: `C:\Users\DOJIVERSE\Desktop\바인\자판기 사진` (저장소 밖, 커밋하지 않는다)
- 번호표: `~/pickpos/_content/사진목록.tsv` (482장에 1번부터 번호) — **픽포스 저장소 것을 읽기만 한다**
- ~~1번부터 위로 올라간다~~ → **번호 순서대로 쓰면 같은 장소(폴더) 사진이 며칠씩 이어진다**(2026-09-21~23 관악·광진·구로 글이 전부 괴산 주유소 사진 — 사용자 지적). 그래서 이제는 도구가 고른다:
  `powershell -NoProfile -ExecutionPolicy Bypass -File "C:/Users/DOJIVERSE/사이트관리/도구/자판기사진고르기.ps1" -Site 픽프리`
  → 후보 5장(하루 = 장소 폴더 하나 · 픽프리가 최근 10일 안에 쓴 장소와 픽포스·H포스가 최근 3일 안에 쓴 장소 제외 · 폴더는 무작위, 다 돌면 가장 오래전에 쓴 폴더부터 · 세 사이트가 이미 쓰거나 건너뛴 사진은 안 나옴). 1번부터 열어 확인하고 안 되면 다음 후보. 기록은 `_content/사진사용기록.md` 에 지금처럼 남긴다(도구가 이 표를 읽는다)
- 세 사이트가 같은 사진을 다시 쓰지 않는 것도 도구가 맡는다(2026-09-19 "겹쳐도 된다" 결정은 이 도구로 대체)
- 사진은 **반드시 Read 로 열어 확인**한다. 아래는 건너뛰고 다음 번호로(기록에 "건너뜀"과 이유를 남긴다):
  - 사람 얼굴이 알아볼 정도로 나온 사진
  - 고객사 상호·간판이 크게 읽히는 사진
  - 냉동 쇼케이스·정육 장비가 주인공인 사진(자판기 글에 안 맞는다)
  - 회전 후 세로로 지나치게 긴 사진(비율 0.5 이하)
- **사진에 보이는 공간에 업종을 맞춘다.** 폴더 이름의 지역은 무시한다
- 축소:
  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File _content\사진줄이기.ps1 -Src "{원본 절대경로}" -Out "{YYYY-MM-DD}-{지역}-{업종}.jpg"
  ```
  → `assets/img/review/` 에 긴 변 1200px, 150KB 내외로 저장된다. **줄인 결과를 다시 열어 눕지 않았는지 확인**

### ⚠️ 사진 출처 문구 (반드시 넣는다)

사진의 실제 장소와 글의 지역이 다르므로, 글 하단 `.art-note` 에 이 문장을 그대로 넣는다.

> ※ 사진은 픽프리가 시공한 설치 사례이며, 글에 적힌 지역의 현장 사진은 아닙니다.

`alt` 와 figcaption 에도 **"{지역}에 설치한"** 이라고 쓰지 않는다.
`alt` 는 `"{업종} 음료·스낵 무인자판기 설치 현장 - 픽프리"` 형태, figcaption 은 구성 설명 + `"픽프리가 시공한 설치 사례입니다."`

## 지어내지 않는다

- 특정 업소명·매출·계약 건수·설치 대수는 쓰지 않는다. 지역의 실제 동·상권 이름까지만.
- 학교 이름을 쓸 일이 있으면 정식 명칭으로(○○고등학교). 확인이 안 되면 학교 이름을 아예 쓰지 않는다.
- 카드수수료·수익률 같은 숫자는 가정임을 밝히거나 쓰지 않는다.

## 발행 절차

1. `git status` 깨끗한지 → `git pull --ff-only origin main`
2. `_content/후기지역목록.md` 에서 다음 지역, `_content/사진사용기록.md` 에서 다음 사진 번호를 고른다
3. 사진을 **열어서 확인** → 업종 결정 → 축소 스크립트 실행 → 줄인 사진 다시 확인
4. 기준 글(가장 최근 후기)을 복사해 `review/{새파일}.html` 작성, 내용을 전부 교체
   (title·description·canonical·og·twitter·JSON-LD 2개 전부 새 글로. **상단 메뉴·푸터는 그대로 둔다**)
5. `review/index.html` 의 `<div class="plist">` 맨 앞에 카드 1개 추가
   (같은 파일 아래쪽 "전국 설치 현장" 갤러리 48장은 건드리지 않는다 — 카드는 `.plist` 안에만 넣는다)
6. `sitemap.xml` 에 한 줄 추가 (`priority 0.6`, `changefreq monthly`, `lastmod` 는 글 날짜)
   ```xml
   <url><loc>https://pickfree.co.kr/review/{파일명}</loc><lastmod>{DATE}</lastmod><changefreq>monthly</changefreq><priority>0.6</priority></url>
   ```
7. `_content/후기지역목록.md` 상태 칸에 `✅ {DATE} · 사진 {번호}({폴더}) · {업종}` 기록
8. `_content/사진사용기록.md` 표에 한 줄 추가(건너뛴 번호도)
9. 게시:
   ```
   git add review/{새파일}.html review/index.html assets/img/review/{새사진}.jpg sitemap.xml _content/후기지역목록.md _content/사진사용기록.md
   git commit -m "후기 추가: {지역} {업종} 자판기 ({DATE})"
   git pull --rebase --autostash origin main && git push origin main
   ```

## 발행 전 체크

- [ ] 사진이 눕지 않았고 얼굴·상호가 크게 안 나온다
- [ ] `.art-note` 사진 출처 문구가 있다
- [ ] canonical·og:url 이 새 글 주소다 (복사한 글 주소가 남아 있으면 안 된다)
- [ ] 지역 페이지 `region/{slug}-vending.html` 로 링크가 걸려 있다
- [ ] 목록 페이지 카드와 사이트맵 줄을 둘 다 넣었다
- [ ] 지어낸 숫자·업소명이 없다
